# Code Smells Reflection

## What code smells did you find in your code?
- Magic numbers used in grading logic.
- Repeated print statements.
- Commented-out debug code.
- Generic/inconsistent variable names.

## How did refactoring improve the readability and maintainability of the code?
- Constants made the logic easier to understand and update.
- Helper functions reduced repetition and improved modularity.
- Cleaned-up structure made the file more readable and easier to test.

## How can avoiding code smells make future debugging easier?
- Clearer names and logic make bugs easier to spot.
- Removing repetition means fewer places for bugs to hide.
- A clean, consistent structure means future developers (or me later) can quickly find and fix problems.
