# Chrome Extensions Setup

## Which extensions did you install? Why?

1. **React Developer Tools**: 
   - I installed this extension to inspect React components and view their state and props. It helps in debugging React apps by providing an easy way to track component behavior and performance.

2. **Redux DevTools**: 
   - This extension is crucial for debugging Redux state management. It allows me to view state changes, dispatched actions, and time travel through the app’s state.

3. **JSON Viewer**: 
   - I installed this extension to prettify JSON responses. It makes it easier to read and understand API responses, especially when dealing with large JSON objects.

4. **Lighthouse**: 
   - I added Lighthouse to run performance audits on my web apps. It provides valuable insights on performance, accessibility, SEO, and other best practices for web apps.

## What was the most useful thing you learned?

The most useful thing I learned was how Lighthouse can help audit and optimize web app performance. It provides detailed feedback on how to improve areas such as load time, accessibility, and overall user experience, which is essential for building performant web applications.
