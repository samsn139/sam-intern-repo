# Cyber Security Guidelines

## Reflections

### What security measures do you currently follow, and where can you improve?
Currently, I:
- Use strong, unique passwords for each account.
- Enable two-factor authentication (2FA) where possible.
- Avoid clicking on suspicious links or downloading unknown attachments.
- Regularly update my software and security patches.

Areas for improvement:
- Implementing a password manager (eg. iCloud KeyChain) for better security and convenience.
- Being more vigilant about phishing attempts and verifying sender identities.

### How can you make secure behaviour a habit rather than an afterthought?
- Establishing routines, such as checking security settings regularly.
- Using reminders to update passwords periodically.
- Incorporating security awareness into daily workflows.

### What steps will you take to ensure your passwords and accounts are secure?
- Use a password manager to generate and store strong passwords.
- Enable 2FA for all critical accounts.
- Regularly review and update passwords, especially after a security incident.
- Never reuse passwords across multiple accounts.

### What would you do if you suspected a security breach or suspicious activity on your account?
- Immediately change the compromised password and enable 2FA.
- Report the incident to the IT/security team.
- Review recent activity logs for any unauthorized access.
- Notify relevant stakeholders if sensitive data is at risk.
