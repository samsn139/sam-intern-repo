## Data Privacy & Confidentiality Reflection

### Steps to Ensure Secure Data Handling in Daily Tasks
- Follow Focus Bear’s privacy policy guidelines strictly.
- Use strong passwords and enable two-factor authentication for all accounts.
- Avoid sharing confidential data over unsecured communication channels.
- Regularly update software and security patches to minimize vulnerabilities.
- Log out of work-related systems when not in use.

### Storing, Sharing, and Disposing of Sensitive Information Safely
- Store confidential data in encrypted or access-restricted locations.
- Use company-approved cloud storage or internal systems instead of personal devices.
- Do not share passwords or sensitive information via email or chat applications.
- Shred or securely delete any unnecessary sensitive documents.
- Double-check recipient details before sending confidential emails.

### Common Mistakes Leading to Data Privacy Issues & Prevention Measures
- **Weak Passwords:** Use strong, unique passwords and a password manager.
- **Phishing Attacks:** Verify links and sender details before clicking on emails.
- **Unsecured File Sharing:** Use company-approved secure file transfer methods.
- **Accidental Data Exposure:** Be mindful of screen-sharing during virtual meetings.
- **Failure to Log Out:** Always log out of systems when leaving shared devices.

### Key Learning & Security Measure to Implement
- **Habit to Improve Data Security:** Use strong passwords and a reliable password manager.
- **Security Measure:** Never leave a device unlocked and unattended.
